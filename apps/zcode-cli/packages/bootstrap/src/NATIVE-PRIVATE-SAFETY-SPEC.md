Owner: disposable Node runner owns a single three-turn V4 command sequence, child owns selected credentials, Model observer owns HTTP reservation/dispatch and Model-call counts, native runtime owns turns and permission identity. Fake and explicit live use the **same** parent controller, child and cleanup; fake injects a local synthetic Anthropic server/config, live resolves only two approved local Anthropic routes privately. For these two Anthropic-message routes, the trusted existing-Model transport buffers each SSE event / nonstream JSON content and rejects any nonfixture `tool_use` **before SDK/tool execution** without rewriting valid body bytes. Borrowed WebFetch HTTP port independently denies all requests, including preapproved URL requests; FS/exec only permit exact fixture operations. Empty disposable HOME/worktree, no configured MCP/plugins/subagents or inherited secrets before imports. No alternate executor or JSON model callback.

No live paid calls in CI or this lane.
