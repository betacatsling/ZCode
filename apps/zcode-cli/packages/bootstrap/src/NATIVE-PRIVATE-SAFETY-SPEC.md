# Native private safety gate (no automatic paid qualification)

Owner: disposable Node runner owns a single three-turn V4 command sequence, child owns selected credentials, Model observer owns HTTP reservation/dispatch and Model-call counts, native runtime owns turns and permission identity. Fake and explicit live use the **same** parent controller, child and cleanup; fake injects a local synthetic Anthropic server/config, live resolves only two approved local Anthropic routes privately. No default credential read. No other tools/networks: V4 `createSession` schema drops `toolAllowlist`. The Node-only private composition must override the *effective* runtime config after the presentation/provider spread to register only fixture tools, disabling dynamic workflows; registration must NOT project to permission `allowedTools` (which would silently preapprove Write/Bash). Independently, for these two Anthropic-message routes, the trusted existing-Model transport buffers each SSE event / nonstream JSON content and rejects any nonfixture `tool_use` **before SDK/tool execution** without rewriting valid body bytes. Treat `data:` without a space, multiline data and CR/CRLF as valid SSE; malformed/unknown event fields fail closed before any SDK release. Borrowed WebFetch HTTP port independently denies all requests, including preapproved URL requests; FS/exec only permit exact fixture operations. Empty disposable HOME/worktree, no configured MCP/plugins/subagents or inherited secrets before imports. No alternate executor or JSON model callback.

```text
parent disposable → spawn/exit latch + bounded byte/frame queue → V4 create/subscribe
  → phase1: Read, denied Write → matching terminal → denied output absent
  → phase2: NEW explicit Write + exact Bash → matching terminal + successful matching rows/exit0 + exact effects
  → independently draw nonce & change read file → phase3: matching Read/result then matching final assistant on same turn
  → stdin close → child exit latch → child private whole-artifact and output scan → bounded cleanup → allowlisted report
child Model call → immutable route reservation → validate serialized HTTP method/URL/query/body model before IO
  → dispatch count → fetch(manual redirect, no retry/proxy) → validate model tool_use before SDK
  → sanitize non2xx and JSON error before SDK; suppress SDK raw APICallError console side channel
```

Failure: never proceed on stale session/turn/toolCall permission, old row, mismatched action/cwd, missing matched Read/result/answer or usage inference; no extra Model/HTTP, redirect or tool IO; abort entire route <=240s including scan/removal; reject oversized unterminated stdout, stderr, queued bytes/rows, EOF, exit/close/spawn error and incomplete scan. Cleanup must also bound the wait after SIGKILL (a child with no exit notification is a failed, unverified removal). Child must privately scan actual selected key+endpoint across complete disposable tree and captured stdout/stderr, return only scan boolean/file count; parent requires that proof and reconciles monotonic IPC counts with final child counts and fake server count. No leaked secret/prompt/actual URL in retained results, logs or argv/env. Full scan must reject symlinks and unknown entry types. Usage is observed on each actual existing Model call via invocation-context operation/operationId/trace, SDK finish, and provider usage-field presence at the already guarded transport, not inferred from V4 cumulative totals or stream-vs-generate. Field presence is allowlisted per physical dispatch; SDK-synthesized cache zero is absent, computed total is derived, explicit provider zero is reported. Missing/failed call, missing provider completion or correlation is partial/unknown and blocks usage qualification; the fake title auxiliary currently ends with error-partial, so `usageQualified=false` even when scenarioVerified is true. No claim estimated cost is a provider charge; HTTP reservation/dispatch counts are not interchangeable: each reservation captures its invocation-context callId before awaiting request body; dispatch carries that reservationId even when calls interleave, while uncorrelated attempts are explicitly partial. Permission approval uses native TurnStarted → sourceCommandId + runtimeTurnId + persisted messageId from a trusted bootstrap legacy event observation before any effect; the private projection drops other legacy events from stdout. It joins the admitted command and session to native permission turn/toolCall first, then matches persisted messageId to V4 product terminal and tool rows (never equates runtime ID to product ID). Fresh foreign permission IDs, not merely prior turn IDs, must be denied before mutation. The selected fake endpoint must be echoed by upstream on failure and privately scanned; deliberate leak must fail. Same-controller server must assert actual serialized method/origin/path/query/model/max_tokens/count, with fault injection on the real child transport. Exact fixture Bash pins Node 24 process.execPath + PATH and checks canonical script/cwd and immutable script bytes before borrowed execution; fixture output confirms the binary. It does not promise OS-global sandboxing or malicious same-user filesystem resistance. Model configuration copies the selected local contextWindow/maxTokens for Registry validation, but actual outgoing max_tokens is checked <=4096 at HTTP gate; placeholder option maps are not claimed as configured reasoning/output controls. No live paid calls in CI or this lane.
