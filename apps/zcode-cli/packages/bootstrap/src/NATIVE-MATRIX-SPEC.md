# Native V4 matrix — CLI source-component proof

Private runner scope: default fake mode never opens local credentials; explicit `--live stepfun/step-3.5-flash` or `--live axonhub/deepseek-v4-flash` only may load an existing private local config into memory before injecting a real registry. One route per invocation, at most twelve observed HTTP attempts, no retries, 240 seconds including cleanup. Model invocations and actual transport attempts are separately counted before IO; unknown routes, extra models, and exhausted budgets fail closed. No secrets, endpoints, headers or raw messages may enter reports, logs, argv, environment, V4 account overlay, or retained DB; disposable artifacts are scanned before removal. A terminal requires the matching session and sourceCommandId on a completed turnHeader (not an ACK or old control phase); answer evidence requires a finalized assistant text row on that turn. The permission decision compares exact tool input and scope with an allowlist before effect. Read may not request permission at all, so the trusted private bootstrap also borrows the existing FileSystemPort/ExecutionPort adapters behind a fixture-scope guard: only fixture input Read, exact output Write, and exactly one Bash command in fixture cwd may reach the existing adapters. Unknown operations fail closed. These private guards must be exercised by the same fake V4 child, not only direct unit calls. Failure cancels and performs bounded cleanup without replay. Fake-only proof never claims paid route certification.

A child process runs `runZCodeProtocolAgent` on native stdio/V4; the trusted in-process composition injects a real `ProviderRegistryService`, with the existing `Model` executor targeting a local disposable fake Anthropic upstream. This is not a stub executor, a replacement HTTP model, an account overlay, or a GUI/SSH certification. The subprocess, not the test, owns the session/history/command admission. Fixture request bodies, endpoints and headers are never logged.

Owner/event order: V4 create/subscribe → sendText accepted → fake upstream offers Read/Write/Bash tools → V4 permission decision (Write deny first, then allow, Bash allow only for exact command) → terminal `completedSuccess` projection → next send. The runner must check the denied write left the file absent, the allowed write produced exact content and Bash exited successfully with an exact filesystem effect. Only after the prior terminal projection may the runner change the original file externally; final-turn Read and subsequent answer must demonstrate the newly changed, previously unknown content. No sleep constitutes terminal proof; request/model counts and V4 events are separate evidence. Terminal failure must stop rather than rerun paid routes.

Default startup (no DI) uses isolated fake config paths, no personal profile or real account overlay. It must open the configured relative DB under launch cwd and close on stdio detach. DI remains trusted in-process only; failed boot must dispose acquired resources; `prepareStorageOnly` must not start the registry. Fake tests run without any paid calls or persistent keys. Run `scripts/native-matrix.mjs` from the repository root under the global heavy-slot wrapper; its three serial test files are fixture-only, never a paid runner. Its request count is HTTP requests accepted by the fake upstream, not a separately instrumented provider Model call counter.

`scripts/native-private-runner.mjs` defaults to the fake native matrix. `--live <exact route>` is explicit and uses only the existing local Pi models config to build a trusted in-memory Registry; it never exports credentials to V4, argv or environment. A trusted Node-only Model adapter observes executor calls and SDK transport attempts independently; no executor/client substitute, no request rewriting, no success-response rewriting. It refuses wrong Model/API route and reserves the ≤12 HTTP budget before I/O, disables private-run proxy routing that could bypass the injected fetch, disallows implicit HTTP redirect following, sets SDK retry maxAttempts=1, and sanitizes non-2xx upstream error echo and transport failure causes before they reach SDK persistence. Routes requiring a proxy must fail closed; neither redirect nor proxy can silently consume uncounted attempts. The private logger is disabled specifically for this disposable run because standard status log context includes raw baseURL. The parent caps queued V4 frames (128), per-frame line length (1 MiB), and observed row metadata (2048); it retains only scoped pseudonyms, ACK/start/matching terminal event ordering, approved action kinds/effects, HTTP and Model counters, usage present/absent, child exit, allowlisted failure stage and cleanup facts. The private isolated directory is scanned for synthetic secret/endpoint sentinels then removed, not retained as a transcript. Runtime stops at 230s, then child cleanup has a 3s kill bound and remaining route budget for local artifact scanning. The fake matrix tests error-echo sanitization, mismatched command terminal, unexpected scope and observer limits; no paid calls occur under CI/--help/default/fake. Only MAIN may opt in to one route per invocation after independent review. Source-component proof never certifies GUI/remote transport; scan of *real* credential values and provider results cannot be claimed without an actual approved run.
