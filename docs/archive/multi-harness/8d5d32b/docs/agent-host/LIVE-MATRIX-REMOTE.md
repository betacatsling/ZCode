Reports contain counts, versions, SHA, provider/model/API, file-effect checks and epoch/cancel evidence, plus explicit `unverified` for any skipped pair. Source component execution never certifies GUI quit, SSH detach/reconnect, packaged lifetime, maintenance or P3/P4 product completion.
