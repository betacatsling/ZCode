For each required pair: bounded purposeful deny→approve native file/read/bash/follow-up flow, verify denied file absent, approved file content and test command effect in disposable worktree, and distinguish request counts/usage from claims inferred from text. On first unavailable public seam or sanitized live error, stop paid retries, record exact phase/code and preserve no sensitive raw output. Cleanup only owned fixture directories/children. Default test is gated/skipped; enabled test must visibly fail, not silently substitute models.
