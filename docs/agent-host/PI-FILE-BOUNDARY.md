# Pi file tool boundary (target-local, pinned SDK 0.87.1)

Owner: the Pi target worker's file-tool backend; Host remains the only turn/approval authority. SDK `read`, `write`, `edit` must use injected operations rather than ambient pathname IO. The hook is an approval gate, **not** a process/Bash sandbox: authorized bash commands can access files outside the worktree, and the Pi process is not OS-confined. Do not advertise a filesystem sandbox.

For Linux, resolve a lexically contained path relative to the verified worktree root, then traverse each component with `O_NOFOLLOW|O_DIRECTORY` from an open directory descriptor via `/proc/self/fd/<fd>/<component>`. Open the final file with `O_NOFOLLOW` and regular-file checks. Never reuse a checked absolute pathname for the actual read/write. Pin the worktree root's device/inode on worker initialization and compare on every operation. Symlink components are rejected (including internal links); operations on unsupported OS/proc-fd backends fail closed. No network/provider changes. Read and edit require an existing regular file; write supports creation and existing files only in existing directories; no mkdir recursion. No hardlink confinement is promised (hardlinked files share an inode). Explicitly refuse nonregular files (FIFO/device), including files swapped between hook and operation. The pre-tool hook still validates the path before requesting approval, but is not relied on for race safety. SDK's path resolution and preliminary access calls are not security boundaries.

Sequence: Host accepted turn → Pi tool_call check → optional decision by exact call/turn → SDK tool operations → each operation opens root/parent/final descriptors and only performs IO on the opened file descriptor → tool result. Cancel aborts SDK turn; no new state/replay is introduced. Tests use real temporary directories, swap a validated path to an outside symlink before IO, verify no outside data or mutation, and check unsupported platform failure. This cannot sandbox bash or prevent effects of an already authorized command.
