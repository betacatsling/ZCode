# Anthropic Messages Gateway codec (foundation seam)

Authority: frozen foundation contract, `ModelRequest` / `ModelEvent` in `@zcode/contracts`. This codec translates only; Gateway core alone owns token admission, model binding, HTTP limits and stream cancellation. No separate upstream client, provider credentials, or private provider state is stored here.

## Supported wire subset

`POST /v1/messages`, streaming only, `anthropic-version: 2023-06-01`. Input requires nonempty `model`, positive integer `max_tokens`, `stream: true`, nonempty ordered messages. Optional `system` is string or ordered text blocks (concatenated without introducing characters) and precedes conversation. User/assistant text blocks (or string content), assistant `tool_use` with unique nonempty id and object input, user `tool_result` with matching earlier tool-use id and text-only content, and client `tools` with `name`, optional `description`, `input_schema` object. Interleaving text and tool calls within a single assistant message is representable only for the text concatenation and tool call order; reject text after a tool call or multiple separated text blocks where relative ordering would be lost. Tool results must match outstanding tool calls exactly once, including two results in one user message. Empty user text is permitted. Tool results cannot interleave text or be combined with ordinary user text in one message. Existing `ModelInputMessage` tool messages record the original tool name and `is_error`. Exactly one contiguous system prefix is accepted (wire `system` cannot appear mid-conversation).

`max_tokens` maps to `options.maxOutputTokens`. A text/image user block and an ephemeral cache marker on a *sole* supported text block may be admitted losslessly via ModelInputMessage content/cacheControl; image bytes remain data URLs and never enter logs. The SDK's observed multi-block user message with only the final block cached must still 422 until ModelTextContentBlock supports per-part cacheControl and the selected provider adapter demonstrably maps it to per-part Anthropic cache_control; changing message segmentation or applying the mark to an entire user message would be a semantic change. A sole tool_result block cache marker may be mapped to its tool message cacheControl; each ordered system text block can be a separate system message with its own marker only after provider adapter verifies grouping as an ordered system prefix. Output text/signed thinking blocks retain order and identity. A thinking block must have an opaque provider-original `providerMetadata.anthropic.signature` (the exact AI SDK normalized signature_delta shape); emit this signature before block stop and preserve it as `ModelReasoningContentBlock.providerOptions.anthropic.signature` in subsequent assistant history. If the signature is absent/mismatched, fail the stream rather than reconstruct from plain text. Redacted thinking is not mapped until a verified exact wire form exists. AI SDK inputTokens includes cached tokens, whereas Anthropic input_tokens excludes cache read/write: subtract both from inputTokens and emit their exact counters; reject inconsistent usage. No other sampling/tool-choice/JSON mode parameters are available through `ModelRequest`; reject unrecognized fields (including metadata, service_tier, output_config, thinking, context_management), unsupported semantic beta headers, unknown `anthropic-*` headers, tool variants, unsupported cache hints and rich tool results. Absence of a field is not evidence that its semantics were preserved. Authorization headers are interpreted only by Gateway core, not this codec. Unknown auxiliary paths such as `/v1/messages/count_tokens` and compaction must return explicit unsupported responses through core's fixed-path routing; this codec advertises only `/v1/messages`. Both bodies still carried `metadata.user_id`, `output_config.effort`, `thinking.type:disabled`, `temperature`, and the six beta headers; `context_management` disappeared from the body (not from its beta header). ## Stream sequence and failure

After executor `start` or the first content event, emit `message_start` with zero initial usage, followed by indexed `content_block_start`, zero or more `content_block_delta`, `content_block_stop` per text/tool block. Text deltas are incremental, tool deltas are `input_json_delta`; a completed `tool_call` must agree with parsed accumulated JSON and be a JSON object before its block is stopped. A tool block begins with `input: {}` (placeholder only; no half-complete arguments committed). End with `message_delta` carrying exact mapped stop reason (`stop` -> `end_turn`, `length` -> `max_tokens`, `tool-calls` -> `tool_use`) and replacement usage, then `message_stop`. Input usage is not known until finish and is emitted once in the terminal delta, not added to initial zero. Cache usage is mapped only with verified nonnegative counters, not fabricated; reasoning usage is not a Messages wire usage counter and remains a Model-side detail. No synthetic private signatures or token costs.

Unfinished JSON, invalid event order, missing finish, unknown stop reason, unsupported reasoning, executor error and cancellation produce a terminal structured `event: error` (`error.type`, redacted `error.message`) and never a successful `message_stop`. Do not send `message_delta` with a success stop reason on failure. Core forwards these SSE frames and enforces backpressure. Client cancellation is signaled through the context abort signal; a late finish cannot turn it into success. Wire message IDs are Gateway request IDs; timestamps are not part of Messages SSE.

```text
Gateway binding (owner) -> decoded ModelRequest -> existing Model executor (owner of stream)
        -> codec indexes & validates blocks -> Gateway SSE transport (owner of delivery)
abort signal -> codec terminal error; no success stop
```

No persisted state, replay, or mobile/desktop stream conversion is performed by the codec. Tests use deterministic fake streams, not live-model equivalence. Versioned CLI fake trace and actual routing compatibility remain separate acceptance gates.
