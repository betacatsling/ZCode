**BLOCKING native durable create proof (MAIN needs assign CLI protocol owner):** `apps/zcode-cli/packages/bootstrap/src/zcode-protocol/v4-bridge.ts:310-324` returns `null` admission input for `createSession` WITHOUT `firstInput` (draft); `apps/zcode-cli/packages/bootstrap/src/zcode-protocol-v4/create-session-command-fact.ts:9-46` recovers a global create only via `getSessionInputById(queueItemIdForCommand(commandId))`. Hence after CLI worker restart, a draft-create ACK cannot be recovered by `commands/query(sessionId:null,commandId)` and a retry can allocate another original ID. Need CLI-owned durable global draft-create receipt persisted before ACK, with command ID+intent+original session ID, queried after restart. Core cannot manufacture this in a second queue. Factory intentionally leaves `certifiedCreate` false and native create rejects until that primitive and verified mapping write/sidecar producer exist. Exact caller: `workspace-hierarchy/hierarchyService.ts:138-164` requires `native.certifiedCreate` and `runtime.create(scope,commandId,modelBinding,cwdRelativeToWorktree)`. `NativeRuntimeFactsPort` is `workspace-hierarchy/nativeProductionBridge.ts`, not session/.
