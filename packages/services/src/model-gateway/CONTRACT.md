# Model Gateway contract

`model-gateway` owns loopback Responses and Anthropic Messages ingress plus only the grant/budget/request state required to serve them. The host composition owns session and model selection: it resolves one immutable per-turn BindingPlan, calls the existing `bindHostModel`, and passes that already-bound `Model` into `createGrant` with exactly one authorized protocol. The Gateway does not create another Provider client or infer a route from request data.

`TargetModelGateway` owns one Gateway instance for one target-local Host owner and is shared by target Harness adapters. It rejects requests for a second target and closes its grants and listener with the owner.

Each grant belongs to exactly one configured target and one Host session. It binds one protocol (`openai-responses` or `anthropic-messages`), a frozen model-binding fingerprint, one public model alias, expiry, and strict resource limits. Same-binding renewal extends expiry without changing the bound Model or token; it requires the exact binding fingerprint and cannot revive a revoked grant. A Host may hold one bounded lease for one active Host turn, renew only that turn's lease, and end it on the matching terminal event. Lease renewal never widens the grant's protocol, route, session or model alias. A changed binding requires revoking the old grant and issuing a new token. The opaque session capability is returned once, stored only as a digest, and revocation removes access and aborts active work. It is not a Provider API key. The server never trusts the request's model or endpoint to choose an executor.

The `prompt_cache_key` field sent by the observed Codex version is accepted as bounded compatibility metadata and deliberately not forwarded. This module does not implement prompt caching.

The Responses route remains `POST /v1/responses` with streaming enabled. The Messages route is `POST /v1/messages` (and the pinned Claude CLI query `?beta=true`) with `stream: true`, authenticated through `x-api-key`. A token is authorized for only its grant's protocol; `Authorization: Bearer` and `x-api-key` do not cross-authorize. The pinned CLI's unauthenticated `HEAD /api/hello` is a no-model health check. Count-token and model-listing routes are unsupported. Each decoder rejects unsupported shapes before calling the Model. The Gateway forwards validated messages/tools to the injected `Model.streamText` port and forwards its `AbortSignal`; it never creates a Provider HTTP client or executes tool calls.

No prompt, Authorization value, Gateway token, Provider credential, or model error text is written to logs or returned to the client. Public errors use stable Gateway codes and safe messages. An unrecognized method/path receives a structured error without falling through to a Provider.

The Responses Model request contract preserves `instructions` and leading `system` input in `systemInstructions`, and preserves input `developer` as the distinct `developer` message role. Codex host-managed admission remains limited to an OpenAI Responses Model adapter that maps both layers. For Messages, top-level `system` maps to `systemInstructions`, ordered `system` messages remain ordered Model `system` messages, and `developer` is rejected because Anthropic has no corresponding role; it is never silently flattened. Adjacent Responses function calls or Anthropic `tool_use` blocks form one assistant tool-call batch. Every function/tool result must match exactly one earlier call. The Messages path admits only the pinned CLI's verified disabled-thinking/cache/context-management request path; any opaque thinking/signature or Model reasoning stream is rejected rather than emitted as unsigned thinking or ordinary text. Messages `output_config.effort` must match the already-bound Model option.

Responses SSE events keep their existing increasing `sequence_number` and complete item lifecycle. Messages SSE events use the Anthropic `message_start`, content block start/delta/stop, `message_delta`, and `message_stop` lifecycle; text, tool argument JSON, finish reason and usage snapshots retain their protocol semantics. Messages requires exact Model-reported input usage before stream start and output usage at finish; it does not estimate tokens or fabricate a count if the bound executor omits one. Gateway settlement counts the Model executor usage once; it does not estimate Anthropic price or add CLI-side values to the Model executor's accounting.

The transport binds only IPv4/IPv6 loopback. Closing the service revokes every grant and aborts active requests. A grant capability is unauthorized after its grant/active-turn lease expires, and an in-flight request aborts when its authorization window ends. Output budget reservation is settled to the terminal Model executor usage when available; an interrupted or unfinished request consumes its reservation.
